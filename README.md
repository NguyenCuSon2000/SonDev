# Birthday Celebration Website

This is a static website created for a birthday celebration. It features a festive design with interactive elements, including a birthday greeting, a birthday cake with candles and flowers, and a gift box that links to a special page.

## Project Structure

```
birthday-celebration-website
├── src
│   ├── index.html        # Main HTML document for the birthday celebration
│   ├── css
│   │   └── style.css     # Styles for the website
│   ├── js
│   │   └── main.js       # JavaScript functionality for interactive elements
│   └── assets
│       └── (placeholders for images or media)
├── .gitignore            # Files and directories to be ignored by Git
├── package.json          # Configuration file for npm
└── README.md             # Documentation for the project
```

## Features

- **Birthday Greeting**: A warm and cheerful greeting to celebrate the special day.
- **Interactive Elements**: Clickable gift box that navigates to a special page (MyLove.html).
- **Audio Playback**: Plays the "Happy Birthday" song to enhance the celebration atmosphere.
- **Visual Effects**: Includes animations for elements like the birthday cake and fireworks.

## Getting Started

To set up and run the website locally, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/birthday-celebration-website.git
   cd birthday-celebration-website
   ```

2. **Install Dependencies** (if any):
   ```bash
   npm install
   ```

3. **Open the Website**:
   Open `src/index.html` in your web browser to view the birthday celebration website.
